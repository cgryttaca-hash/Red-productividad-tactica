RECUPERACIÓN DEL ERROR "eventData exceeded the quota"
====================================================

QUÉ SE CORRIGIÓ
---------------
Los eventos ya no se guardan como un JSON grande en localStorage.
Ahora se almacenan en IndexedDB, que está diseñado para bases locales de
mayor tamaño.

La aplicación conserva en localStorage únicamente datos pequeños:
- Fecha de actualización.
- Nombre del archivo.
- Estado del equipo.
- Estado de publicación Firebase.

RECUPERACIÓN AUTOMÁTICA
-----------------------
Al abrir esta versión:
1. Busca un respaldo anterior llamado eventData.
2. Si existe y es legible, lo mueve a IndexedDB.
3. Elimina el contenido grande de localStorage.
4. Inicio, Eventos, Minuta y Firebase leen la misma base IndexedDB.

INSTALACIÓN
-----------
1. Sube todos los archivos de esta carpeta al repositorio.
2. Espera a que GitHub Pages finalice la publicación.
3. Abre la página y presiona Ctrl + F5.
4. Espera unos segundos mientras se realiza la migración.
5. Abre Eventos y comprueba que aparecen los registros.
6. Si el intento fallido no alcanzó a guardar los eventos, pulsa
   Archivo maestro > Actualizar ahora una sola vez.

IMPORTANTE
----------
No borres los datos del sitio antes de abrir esta versión, porque el sistema
intentará recuperar automáticamente el respaldo anterior.

Si Chrome solicita nuevamente permiso para leer el Excel, pulsa Reconectar.
No necesitas seleccionar otro archivo salvo que haya sido movido o renombrado.
