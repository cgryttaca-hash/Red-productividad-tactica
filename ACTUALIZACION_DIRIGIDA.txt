IMPORTANTE SOBRE FIRESTORE
--------------------------
GitHub Pages no puede publicar reglas de seguridad remotas.

Para que la Agenda Móvil quede realmente protegida, el contenido del archivo
firestore.rules debe estar publicado en Firebase Console:

Firestore Database → Reglas → pegar contenido → Publicar

Sin ese paso, el código cliente puede mostrar login, pero la seguridad real
de los datos seguirá dependiendo de las reglas que estén activas en Firebase.
