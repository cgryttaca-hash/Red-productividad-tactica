ACTIVACIÓN DE FUNCIONES AVANZADAS
================================

FUNCIONAN SIN CONFIGURACIÓN ADICIONAL
-------------------------------------
- Diagnóstico local.
- Validación del Excel.
- Respaldos y restauración.
- Auditoría local y exportación.
- PWA y página offline.
- Mantenimiento programado.
- Agenda en tiempo real con la configuración Firebase existente.
- Registro básico de equipos después de publicar firestore.rules.

REQUIEREN UNA ACCIÓN EXTERNA
----------------------------
1. FIRESTORE RULES
   Publicar el contenido de firestore.rules desde Firebase Console.

2. APP CHECK (OPCIONAL)
   Crear una clave reCAPTCHA/App Check y pegarla en
   FIREBASE_APP_CHECK_SITE_KEY dentro de js/firebase-config.js.

3. NOTIFICACIONES CON EL NAVEGADOR TOTALMENTE CERRADO (OPCIONAL)
   Requieren una clave VAPID y un servicio de envío FCM o backend.
   La clave pública se coloca en FIREBASE_VAPID_KEY.

4. USUARIOS FIREBASE CENTRALIZADOS (OPCIONAL)
   Crear, eliminar o restablecer cuentas de Firebase Authentication de otros
   usuarios requiere Admin SDK en un backend o Cloud Functions.
   La administración local incluida en usuarios.html no necesita backend.

No se incluyeron claves privadas ni credenciales de servicio dentro del sitio.
