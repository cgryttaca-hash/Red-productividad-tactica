ACTUALIZACIÓN CONTROLADA — PASOS DE INSTALACIÓN
=================================================

Este paquete contiene únicamente los archivos nuevos o modificados.
NO elimines los demás archivos del repositorio.

1. En GitHub abre:
   cgryttaca-hash / Red-productividad-tactica

2. Pulsa Add file > Upload files.

3. Arrastra TODO el contenido de esta carpeta:
   - index.html
   - eventos.html
   - minuta.html
   - agenda_movil.html
   - firestore.rules
   - sw-mobile.js
   - carpetas css y js

4. Confirma que GitHub reemplace los archivos del mismo nombre.
   Los archivos existentes js/eventos.js, js/minuta.js, css/eventos.css y
   css/minuta.css deben permanecer en el repositorio.

5. Haz Commit changes con el mensaje:
   Control de equipos, auditoría y nueva agenda móvil

6. En Firebase Console abre Firestore Database > Reglas.
   Copia TODO el contenido del archivo firestore.rules de este paquete.
   Pégalo y pulsa Publicar. Esto habilita la colección eventos_cambios.

7. Abre la página principal y pulsa Ctrl + F5:
   https://cgryttaca-hash.github.io/Red-productividad-tactica/

8. PRIMER ACCESO EN CADA EQUIPO
   - Escribe un nombre para el equipo.
   - Ingresa el correo y contraseña del propietario.
   - Autoriza el equipo.
   - Vincula el Excel una sola vez.
   La sesión y la referencia se guardan en ese navegador.

9. PUBLICACIÓN
   Al detectar cambios en el Excel, el sistema publica automáticamente si
   la sesión del propietario sigue activa. También puedes usar Publicar ahora.

10. AGENDA MÓVIL
   https://cgryttaca-hash.github.io/Red-productividad-tactica/agenda_movil.html

IMPORTANTE
- No uses modo incógnito.
- No borres los datos/cookies del sitio si deseas conservar la sesión.
- No muevas ni renombres el Excel después de vincularlo.
- Chrome/Edge pueden pedir reconectar el archivo si el permiso del sistema
  operativo o del navegador fue revocado; la aplicación ya no abre el panel
  automáticamente en cada visita.
- Las notificaciones del navegador deben activarse una vez en cada equipo.
- Los avisos en tiempo real funcionan mientras la agenda esté abierta.
  Para avisos con la página totalmente cerrada se requiere configurar
  Firebase Cloud Messaging y una clave VAPID adicional.
- Una página web no puede impedir que una persona escriba manualmente otra URL.
  La agenda móvil no muestra enlaces administrativos y bloquea el regreso
  accidental mediante el botón Atrás.
