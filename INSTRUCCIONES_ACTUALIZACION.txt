INSTALACIÓN
===========

1. Descomprime el ZIP.
2. Entra a la carpeta Red-productividad-tactica-main.
3. Sube TODO su contenido a la raíz del repositorio:
   cgryttaca-hash/Red-productividad-tactica
4. Confirma el reemplazo de archivos.
5. Espera la publicación de GitHub Pages.
6. Abre:
   https://cgryttaca-hash.github.io/Red-productividad-tactica/
7. Presiona Ctrl + F5.

PRIMER USO
----------
- Completa la autorización del equipo.
- Selecciona el Excel.
- Espera a que indique Archivo conectado y Nube conectada.
- Pulsa Publicar ahora si deseas forzar la primera publicación.

RECUPERACIÓN
------------
No borres los datos del navegador antes de abrir esta versión. El sistema
recupera la base anterior de localStorage y la mueve a IndexedDB cuando existe.

FIREBASE
--------
El proyecto ya contiene firebase-config.js y el UID del propietario.
El archivo firestore.rules contiene las reglas correctas para lectura móvil y
escritura exclusiva del propietario.
