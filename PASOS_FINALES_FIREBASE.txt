PASOS FINALES PARA ACTIVAR FIREBASE
===================================

La configuración de la aplicación web y el UID del propietario ya están
colocados dentro del proyecto.

1. FIRESTORE > REGLAS
   - Abre el archivo firestore.rules incluido en este proyecto.
   - Copia todo su contenido.
   - En Firebase Console entra en Firestore Database > Reglas.
   - Reemplaza el contenido actual y pulsa Publicar.

2. AUTHENTICATION > MÉTODO DE ACCESO
   Confirma que estén habilitados:
   - Correo electrónico/contraseña.
   - Anónimo.

3. AUTHENTICATION > CONFIGURACIÓN > DOMINIOS AUTORIZADOS
   Agrega tu dominio de GitHub Pages, por ejemplo:
   TU_USUARIO.github.io

4. SUBIR A GITHUB
   - Reemplaza los archivos actuales del repositorio por los de esta carpeta.
   - Confirma los cambios y espera la publicación de GitHub Pages.
   - Abre el sitio con Ctrl + F5.

5. PRIMERA PUBLICACIÓN
   - Abre la página principal desde GitHub Pages.
   - Vincula el Excel.
   - Inicia sesión como propietario con el correo creado en Firebase.
   - Pulsa Publicar ahora.
   - No compartas la contraseña del propietario.

6. PÁGINA MÓVIL
   La URL será similar a:
   https://TU_USUARIO.github.io/TU_REPOSITORIO/agenda_movil.html

   Los visualizadores entrarán como usuarios anónimos y solo podrán leer.
