CONFIGURACIÓN DE SEGURIDAD AVANZADA
===================================

La versión 3.0 funciona sin estos elementos opcionales.

1. FIREBASE APP CHECK
   - Crea una aplicación Web de App Check en Firebase Console.
   - Selecciona reCAPTCHA v3.
   - Copia la clave pública en:
     js/firebase-config.js
     FIREBASE_APP_CHECK_SITE_KEY = "CLAVE_PUBLICA";

2. NOTIFICACIONES PUSH CON EL NAVEGADOR CERRADO
   - Activa Cloud Messaging en Firebase.
   - Genera una clave VAPID Web Push.
   - Copia la clave pública en:
     js/firebase-config.js
     FIREBASE_VAPID_KEY = "CLAVE_VAPID";

   Además se necesita un emisor seguro (Cloud Function o servidor) para enviar
   los mensajes. Una página estática de GitHub Pages no puede guardar una clave
   privada ni enviar notificaciones administrativas de forma segura.

3. USUARIOS CENTRALIZADOS
   Las cuentas locales actuales se almacenan mediante PBKDF2 en cada navegador.
   Crear y eliminar usuarios de Firebase Authentication desde una página web
   requeriría exponer privilegios administrativos, lo cual no es seguro.
   Para centralizar contraseñas se necesita una Cloud Function o backend con
   Firebase Admin SDK.

4. REGLAS DE FIRESTORE
   Publica el archivo firestore.rules incluido en el ZIP después de actualizar.
