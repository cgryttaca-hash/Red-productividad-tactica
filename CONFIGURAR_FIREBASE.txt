CONFIGURACIÓN DE FIREBASE PARA AGENDA MÓVIL EN TIEMPO REAL
==========================================================

OBJETIVO
--------
- La computadora propietaria vincula y lee el Excel local.
- Solo la hoja/eventos normalizados se publican en Cloud Firestore.
- agenda_movil.html muestra los eventos en tiempo real y no permite editar.
- Los visualizadores entran automáticamente con autenticación anónima.
- Solo el UID del propietario puede crear, actualizar o eliminar eventos.

PASO 1. CREAR EL PROYECTO
-------------------------
1. Entra en Firebase Console.
2. Crea un proyecto nuevo.
3. No es obligatorio activar Google Analytics.
4. Dentro del proyecto, registra una aplicación Web (icono </>).
5. Pon un nombre, por ejemplo: Gestion Eventos Web.
6. Copia el objeto firebaseConfig que aparece.

PASO 2. firebaseConfig COMPLETADO
----------------------------------
El archivo js/firebase-config.js ya contiene la configuración Web del proyecto
red-productividad-tactica. No necesitas modificarlo.

No uses claves privadas ni archivos JSON de cuentas de servicio.
La configuración web de Firebase se publica en el navegador por diseño.
La seguridad depende de Authentication y firestore.rules.

PASO 3. HABILITAR AUTHENTICATION
--------------------------------
1. Abre Authentication en Firebase Console.
2. Pulsa Comenzar.
3. En Métodos de acceso habilita:
   - Correo electrónico/contraseña.
   - Anónimo.

Correo/contraseña se usa para el propietario.
Anónimo se usa para la agenda móvil de solo lectura.

PASO 4. CREAR EL USUARIO PROPIETARIO
------------------------------------
1. En Authentication > Usuarios, agrega un usuario.
2. Escribe el correo y una contraseña segura.
3. El UID del propietario ya fue colocado en js/firebase-config.js.
4. No compartas la contraseña del propietario.

PASO 5. CREAR CLOUD FIRESTORE
-----------------------------
1. Abre Firestore Database.
2. Pulsa Crear base de datos.
3. Selecciona modo Producción.
4. Elige una región cercana a los usuarios.

PASO 6. PUBLICAR LAS REGLAS
---------------------------
1. Abre el archivo firestore.rules incluido en este proyecto.
2. El UID real ya está incluido en firestore.rules.
3. En Firebase Console abre Firestore Database > Reglas.
4. Reemplaza el contenido por el contenido de firestore.rules.
5. Pulsa Publicar.

Las reglas permiten:
- Lectura a usuarios autenticados, incluidos los visualizadores anónimos.
- Escritura únicamente al UID propietario.
- Bloqueo total de cualquier otra colección.

PASO 7. SUBIR A GITHUB
----------------------
1. Sube todos los archivos del proyecto al mismo repositorio.
2. Confirma los cambios.
3. Espera que GitHub Pages termine la publicación.
4. Abre la página principal con Ctrl + F5.

PASO 8. PRIMERA PUBLICACIÓN
---------------------------
1. Abre index.html o eventos.html desde GitHub Pages.
2. Vincula el Excel maestro como ya se hacía.
3. Pulsa el control Publicación móvil / Iniciar sesión.
4. Ingresa el correo y contraseña del usuario propietario.
5. Pulsa Publicar ahora.
6. Abre agenda_movil.html en otro PC o celular.

Después de iniciar sesión como propietario:
- Cada actualización válida del Excel programa una publicación automática.
- También puedes usar Publicar ahora.
- La sesión queda guardada en ese navegador.

ENLACE MÓVIL
------------
Si tu sitio es:
  https://USUARIO.github.io/REPOSITORIO/

La agenda será:
  https://USUARIO.github.io/REPOSITORIO/agenda_movil.html

QUÉ SE PUBLICA
--------------
Se publican campos normalizados de Eventos:
- Fecha.
- Empresa.
- Escenario y piso.
- Horario del evento.
- Horario A&B.
- Descripción de alimentación.
- Cantidad de personas.
- Acomodación.
- Modalidad de servicio.
- Medio de pago.
- Estado.
- Observación.
- Hoja de origen.

No se publica el archivo Excel completo ni se sube el archivo al repositorio.

COMPORTAMIENTO SIN LA PC PROPIETARIA
------------------------------------
Si la PC propietaria está apagada, la agenda móvil sigue mostrando la última
publicación guardada en Firebase. Los cambios nuevos se publicarán cuando la
página propietaria vuelva a abrirse, lea el Excel y tenga sesión iniciada.

SOLUCIÓN DE ERRORES
-------------------
"Firebase aún no está configurado"
- Revisa js/firebase-config.js y confirma que no quede REEMPLAZAR.

"Acceso bloqueado" en agenda_movil.html
- Habilita el proveedor Anónimo en Authentication.

"Missing or insufficient permissions"
- Publica firestore.rules y comprueba que el UID coincida exactamente.

"La cuenta no coincide con el UID propietario"
- Copia el UID correcto desde Authentication > Usuarios.

No aparecen cambios nuevos
- Guarda el Excel.
- Regresa a la pestaña propietaria.
- Revisa que Archivo maestro diga Conectado.
- Revisa que Publicación móvil diga Nube conectada.
- Pulsa Publicar ahora para comprobar.
