ACCESO Y USUARIOS — 3.5.0
===========================

ROLES
-----
Administrador:
- Accede al panel completo, sincronización, usuarios y herramientas administrativas.
- Puede crear usuarios, asignar rol Administrador/Usuario, activar/desactivar y cambiar contraseñas.

Usuario:
- El Inicio muestra únicamente Eventos, Minuta y Agenda Móvil.
- No se muestran menú lateral, Excel, Firebase administrativo, auditoría ni configuración.
- La información publicada por el Administrador se descarga automáticamente desde Firebase.
- Las notificaciones generales pueden activarse desde el Inicio.

CONTRASEÑAS
-----------
- La recuperación pública desde login.html fue eliminada.
- Después de crear o cambiar una contraseña, la interfaz nunca vuelve a mostrarla.
- El cambio de contraseña de otra cuenta requiere una sesión con rol Administrador.
- Las contraseñas se guardan localmente mediante PBKDF2 y no se publican en Firebase.

SESIONES
--------
- Cierre automático al llegar la medianoche local del dispositivo.
- Cierre automático después de 1 hora sin actividad.
- Cinco minutos antes se muestra un aviso con cuenta regresiva.
- La actividad se comparte entre pestañas del mismo navegador.
- Si un Administrador desactiva un usuario o cambia su rol en otra pestaña, la sesión se actualiza o se cierra automáticamente.

SINCRONIZACIÓN DEL USUARIO
--------------------------
- El usuario normal no necesita seleccionar ni actualizar el Excel.
- El sistema escucha la publicación de Firebase y actualiza eventData automáticamente.
- Eventos y Minuta continúan usando su lógica original y reciben el evento eventDataUpdated.

NOTA SOBRE CUENTAS
------------------
Las cuentas de acceso continúan siendo locales al navegador actual. La información operativa
(Eventos/Minuta/Agenda) sí se mantiene sincronizada desde Firebase. Para cuentas compartidas
entre dispositivos se requiere autenticación centralizada mediante backend/Firebase Auth con
roles administrados de forma segura.
